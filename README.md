# CN-website-
Website for the server Celestial Network

## GitHub Pages deployment

This repository is ready to deploy as a static site on GitHub Pages.

- `index.html` is the site entry point.
- `.github/workflows/pages.yml` deploys the site from `main` automatically.
- `.nojekyll` ensures GitHub Pages does not run Jekyll processing.

Once GitHub Pages is enabled, the public URL will be:

`https://lostsignal404.github.io/CN-website-/`

If you want a custom domain, add a `CNAME` file and update repository Pages settings.
